# -Projeto Bootstrap

## -Visão Geral

O projeto consiste em uma página web desenvolvida com HTML, CSS e Bootstrap, colocando em prática conceitos de estruturação, estilização e responsividade.

## -Tecnologias Utilizadas

- **HTML5:** estruturação do conteúdo da página.
- **CSS3:** estilização e personalização da interface.
- **Bootstrap:** framework utilizado para criação de layouts e componentes responsivos.

## -Como Executar o Projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/Mur1llo/projeto-bootstrap.git
   ```

2. Entre na pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em seu navegador para visualizar a página.

**Observação:** caso o projeto utilize bibliotecas ou arquivos externos, verifique se todas as dependências estão disponíveis antes de executar.


## -Objetivo Acadêmico

Este projeto tem como finalidade aprimorar meus conhecimentos em desenvolvimento front-end, praticando a criação de páginas web, organização de código e utilização do framework Bootstrap.
