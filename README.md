# -Projeto Bootstrap

## -Tecnologias utilizadas

- HTML5
- CSS3

## -Sobre o projeto

Este projeto foi desenvolvido durante meus estudos em Análise e Desenvolvimento de Sistemas (ADS), colocando em prática conceitos de estruturação de páginas, estilização e desenvolvimento de interfaces responsivas.

## -Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
